# Design Request

Веб-приложение на Django для оформления и обработки заявок на дизайн помещений. Пользователь может зарегистрироваться, создать заявку с описанием и фотографией, а администратор — обработать её, изменить статус и добавить результат работы.

Проект создан в учебных целях для практики разработки серверных приложений на Django, работы с моделями, формами, авторизацией, загрузкой файлов и административными сценариями.

## Возможности

### Для пользователей

- регистрация и вход в аккаунт;
- создание заявки на дизайн;
- указание названия, описания и категории заявки;
- загрузка фотографии помещения или плана;
- просмотр собственных заявок;
- фильтрация заявок по статусу;
- удаление новой заявки;
- просмотр профиля пользователя;
- получение информации о результате выполненной работы.

### Для администратора

- доступ к панели управления заявками;
- просмотр всех заявок;
- фильтрация заявок по статусу;
- создание и удаление категорий дизайна;
- последовательное изменение статуса заявки;
- добавление комментария администратора;
- загрузка фотографии выполненной работы;
- контроль обязательных данных при завершении заявки.

## Статусы заявки

Заявка проходит этапы в следующем порядке:

```text
Новая → Принято в работу → Выполнено
```

После перевода заявки в статус **«Выполнено»** изменить её статус уже нельзя. Для завершения заявки администратор должен добавить комментарий и загрузить изображение результата.

## Модели данных

В проекте используются следующие основные модели:

- `Profile` — дополнительная информация о пользователе;
- `Category` — категория дизайн-заявки;
- `DesignRequest` — заявка пользователя на дизайн.

Для изображений применяются ограничения:

- поддерживаемые форматы: JPG, JPEG, PNG и BMP;
- максимальный размер изображения — 2 МБ.

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/Qu1styy/Design_ap.git
cd Design_ap
```

### 2. Создание виртуального окружения

#### Windows

```bash
python -m venv venv
venv\Scripts\activate
```

#### Linux/macOS

```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Установка зависимостей

Если в проекте используется файл `requirements.txt`:

```bash
pip install -r requirements.txt
```

Минимальный набор пакетов:

```bash
pip install django pillow
```

### 4. Применение миграций

```bash
python manage.py migrate
```

### 5. Создание администратора

```bash
python manage.py createsuperuser
```

Следуйте инструкциям в терминале и укажите логин и пароль администратора.

### 6. Запуск сервера разработки

```bash
python manage.py runserver
```

После запуска приложение будет доступно по адресу:

```text
http://127.0.0.1:8000/
```

Административная панель Django:

```text
http://127.0.0.1:8000/admin/
```

## Важные настройки для разработки

Перед публикацией проекта необходимо заменить секретный ключ Django и отключить режим отладки:

```python
SECRET_KEY = 'your-secret-key'
DEBUG = False
ALLOWED_HOSTS = ['your-domain.example']
```

Также рекомендуется не добавлять в репозиторий:

- `db.sqlite3` с реальными пользовательскими данными;
- содержимое `media/`;
- секретные ключи и переменные окружения.

## Учебные цели

Проект демонстрирует:

- создание Django-проекта и приложения;
- проектирование моделей и связей между ними;
- использование встроенной системы пользователей Django;
- создание и валидацию форм;
- ограничение доступа через `login_required` и проверку администратора;
- обработку загрузки изображений;
- работу с `FileField` и `ImageField`;
- использование миграций;
- работу с Django Templates;
- хранение данных в SQLite;
- реализацию последовательного изменения статусов.

## Ограничения проекта

Это учебное приложение для локального запуска. В текущей версии не предусмотрены отдельный production-сервер, внешняя база данных, полноценная система уведомлений и разграничение ролей помимо обычного пользователя и суперпользователя Django.
